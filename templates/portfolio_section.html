{# portfolio_page.html — renders dist/index.html, a single self-contained file. WHY SELF-CONTAINED: this page is embedded in Google Sites through a sandboxed iframe. Relative asset requests are unreliable there, so the CSS and JS are inlined via {% include %} rather than linked. The only external requests are the two Google Fonts families, which degrade to system fonts if blocked. WHY TABS: a Google Sites embed has a FIXED height and never auto-resizes, so a 10,000px scrolling page shows a tenth of itself at a time. Tabs cut the tallest view to roughly one frame. The panels are real ARIA tabpanels using the `hidden` attribute, so only one is ever in the layout. EMBEDDING ONE SECTION AT A TIME: the same file can serve as an individual embed. `index.html?solo=1&tab=experience` hides the masthead and tab bar and renders that panel alone. Valid tab keys are the data-tab values below. Without ?solo=1, ?tab= / #hash just preselects a tab. COVERAGE CONTRACT: unlike the PDF (which carries 3 flagship one-liners), this page renders EVERY field in resume_data.yaml — all 5 skill categories, all bullets from both jobs, and all 9 projects with overview, features, metrics, skill focus, tech and impact. If you add a field to the YAML, add it here too. One deliberate exception: contact.portfolio_url is not rendered. This page IS that URL, so a self-link would be noise. The PDF does render it, which is where a reader actually needs it. Jinja notes: autoescape is ON, so YAML text is safely escaped. The two {% include %}d asset files pass through unescaped, which is what makes the inlining work. #} {{ profile.name }} — {{ profile.headline.split('|')[0] | trim }} {# Decorative layers.
